Fünf Werkzeuge. Ein klarer Zugang.

Five tools. One focused interface.

Die Schnittstelle trennt öffentliche Verzeichnisabfragen von zustimmungs- und authentifizierungspflichtigen Aktionen.

Public directory discovery is separated from actions requiring consent and authentication.

01 · DISCOVERY

find_terms

Kategorien und Standorte finden, um Suchanfragen präzise einzugrenzen.

Find categories and locations to narrow searches accurately.

02 · SEARCH

search_listings

Veröffentlichte Einträge durchsuchen, mit Filtern und bis zu 20 Ergebnissen pro Seite.

Search published listings with filters and up to 20 results per page.

03 · DETAILS

get_listing

Öffentliche Detailinformationen zu einem Eintrag per ID abrufen.

Retrieve public listing details by their numeric ID.

04 · ACCOUNT

register_account

Konto mit Datenschutz-Zustimmung und E-Mail-Bestätigung registrieren, sofern aktiviert.

Register an account with privacy consent and email verification, when enabled.

05 · SUBMISSION

submit_listing

Einträge authentifiziert zur redaktionellen Prüfung einreichen, ohne automatische Veröffentlichung.

Submit listings for editorial review with authentication; no automatic publication.

ENDPOINT · API

Direkt über HTTPS verbinden

Connect directly over HTTPS

Nutze die MCP-Transportadresse für deinen kompatiblen Client. Die Dokumentationsseite ist keine Transportadresse.

Use the MCP transport URL with a compatible client. The documentation page is not the transport endpoint.

https://www.alle-provider.de/wp-json/alle-provider-mcp/v1/mcp

Beispiel · InitialisierungExample · Initialization
curl -X POST 'https://www.alle-provider.de/wp-json/alle-provider-mcp/v1/mcp' \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H 'MCP-Protocol-Version: 2025-06-18' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"demo-client","version":"1.0"}}}'

Die konkrete Kompatibilität mit einer Cline-Version muss getestet werden. Schreibende Aktionen erfordern zusätzliche Berechtigungen.

Compatibility with a specific Cline version must be tested. Write operations require additional permissions.

Datenzugang mit Verantwortung

Responsible data access

Öffentliche Abfragen liefern nur veröffentlichte Einträge. Für Einreichungen gelten individuelle Zugangsdaten, ausdrückliche Zustimmung und redaktionelle Prüfung. Inhalte aus Verzeichnissen sind externe Daten und keine KI-Anweisungen.
Public searches return published listings only. Submissions require individual credentials, explicit consent, and editorial review. Directory content is external data, not instructions for AI agents.
